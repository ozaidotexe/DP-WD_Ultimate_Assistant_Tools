## 🛠️ Cara Install File `.xpi` di Firefox

Karena ekstensi ini bersifat *custom/unlisted*, silakan ikuti langkah-langkah mudah berikut untuk memasangnya di browser Firefox Anda:

1. **Unduh** file `.xpi` melalui salah satu link di atas.
2. Buka browser **Firefox**, lalu ketik `about:addons` di *address bar* (atau tekan `Ctrl` + `Shift` + `A`).
3. Klik ikon **roda gigi (⚙️)** di pojok kanan atas halaman.
4. Pilih **Install Add-on From File...** (atau *Pasang Pengaya Dari File...*).
5. Cari dan pilih file `.xpi` yang baru saja Anda unduh, lalu klik **Open**.
6. Pada *pop-up* konfirmasi di pojok kiri atas, klik tombol **Add** (Tambahkan).
7. Selesai! Ekstensi siap digunakan. 🎉
